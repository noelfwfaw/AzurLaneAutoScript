## 1. 现象（实例 alas2，2026-10-25 03:27 实测日志）

```
03:27:22.457 │ OPEN_ISLAND score=0.961 tap=639,33
03:27:30.269 │ 声明页向下滚动 1/4
03:27:38.392 │ 声明页向下滚动 2/4
03:27:46.458 │ 声明页向下滚动 3/4
03:27:55.432 │ AGREE score=0.905
03:28:03.760 │ ENTER_ASSIST score=0.930
03:28:11.124 │ 声明页向下滚动 4/4
WARNING  03:28:19.241 │ 辅助启动: failed（声明页滑动 4 次仍未找到按钮）
```

解读（客观事实）：

1. 灵动岛点开了（`tap=639,33` 一次成功，没有出现「换点重试」日志），声明页滑动 3 次后
   `AGREE` 命中（score 0.905），随后 `ENTER_ASSIST` 命中（score 0.930）。
2. `ENTER_ASSIST` 之后**没有再出现** `AGREE` / `ENTER_ASSIST`，也**没有**
   `OPEN_SETTINGS` / `HIDE_ISLAND`，而是直接走了最后一次滑动（4/4）然后失败。
   说明：点击「进入辅助」之后，代码没有识别出任何可用按钮，把当前页面当成了"声明页"。
3. 用户实测确认期望行为：**进入辅助后应点右上角齿轮 → 进入设置 → 点「隐藏灵动岛」**。
   这两步一次都没发生。

## 2. 根因（已定位，含量化线索）

代码位置（行号基于实例当前文件 `submodule/AlasMaaBridge/module/handler/assist.py`）：

- 齿轮分支是**双门控**：`:186-187`
  `if score['assist_panel'] >= self.THRESHOLD and score['assist_gear'] >= self.THRESHOLD_GEAR`
  两个模板必须**同时**达标才会点齿轮（`:105 THRESHOLD = 0.85`、`:107 THRESHOLD_GEAR = 0.90`）。
- 失败分支不打印任何分数：`:193-198`（滑动放弃）、`:222-224`（未检测到灵动岛）直接 return。

**关键量化线索**：模板是拿 QQ 窗口截图（约 1890x1050）缩放对齐到 1280x720 后裁的，
同一来源自测时本页相似度是 **1.000**；而真机上已经命中的两个按钮分数分别是
**AGREE 0.905 / ENTER_ASSIST 0.930** —— 真机整体比素材自测**低约 0.07~0.10**。
按这个偏移推算，`assist_panel`（素材自测本页 1.000、跨页最高 0.654）与
`assist_gear`（素材自测本页 1.000）在真机上很可能落在 **0.83~0.90** 区间，
恰好**跨不过** 0.85 / 0.90 两道门槛，于是齿轮分支从不触发。

**连带放大因素**：`swipe_times` 在 `_run` 开头只初始化一次（`:154`），
声明页就用掉了 3 次（日志 1/4、2/4、3/4），等流程走到"进入辅助之后"时只剩第 4 次，
一旦识别失败就没有重试余量，立刻放弃。

**已排除（不要再往这些方向查）**：

- 不是模板缺失——`AGREE` / `ENTER_ASSIST` 都正常命中。
- 不是点击点错误——日志 `tap=639,33` 是 `ISLAND_POINTS` 的第一个点，一次成功。
- 不是密码错误——密码错误会停留在密码页并**重复**出现 `ENTER_ASSIST`，日志里只出现一次。
- 不是分辨率不符——代码有 1280x720 校验（`:195` 附近），不符会单独告警。
- 不是 150s 超时——03:28:19 结束是因为滑动次数用尽，不是 `:151` 的超时分支。

## 3. 修复步骤

### R1（必须）：补诊断输出 —— 每轮打印全部 6 个 score，失败时保存现场截图

只加观测，不改任何判定逻辑：

  （格式如 `scores: sun=0.96 agree=0.40 enter=0.55 gear=0.83 panel=0.82 hide=0.51`）。
- 在 `:193`（滑动放弃）与 `:222`（未检测到灵动岛）两个失败分支里，
  先把当前 `image` 用 `cv2.imwrite` 写到 `log/assist_fail_<HHMMSS>.png` 再 return，
  并在日志里打印该路径。

**这一步是本次的核心**：没有分数就无法判断到底是阈值问题还是页面变了，不要跳过它去直接调阈值。

### R2（必须，用户侧提供素材后执行）：用真机原生 1280x720 截图重裁 6 个模板
